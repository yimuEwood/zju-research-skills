# Statistics audit report template

## Design map

Capture outcome, estimand, groups, experimental unit, observational unit, hierarchy, assignment, repeated measures, planned `n`, analyzed `n`, and missingness.

## Finding row

| Field | Content |
|---|---|
| ID | Stable issue ID |
| Severity | Critical, major, or minor |
| Anchor | Section/page/figure/table/code location |
| Observed | Verbatim number or faithful description |
| Problem | Specific statistical or reporting defect |
| Consequence | Bias, invalid uncertainty, ambiguity, reproducibility, or wording risk |
| Repair | Smallest valid action and any required reanalysis |
| Status | Confirmed, author query, or triage only |

## Consistency row

Track metric, location A/value, location B/value, expected relation, status, and resolution. Compare group labels, units, denominators, direction, effect estimate, interval, P value, and significance symbol.
