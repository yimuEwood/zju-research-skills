# Chemistry database routing

Use the smallest defensible source set and verify live access/terms.

- General identity and public properties: PubChem and primary literature.
- Curated medicinal chemistry and bioactivity: ChEMBL plus primary assay reports.
- Literature and citation network: Crossref, OpenAlex, PubMed where applicable, Web of Science/Scopus through authorized access.
- Comprehensive substance/reaction searching: SciFinder and Reaxys through current ZJU interactive institutional access.
- Protein/sequence/structure: authoritative domain resources such as UniProt, RCSB PDB, and NCBI as applicable.
- Crystallographic/materials records: the relevant curated crystallographic or materials repository plus the primary publication.
- Patents: official patent databases and stable publication identifiers; legal status requires authoritative verification.
- Safety/regulatory: authoritative safety data and regulatory sources; reconcile jurisdiction and revision date.

Public API availability does not imply unlimited reuse. Record database terms, query date, version, and export boundary.
