# Zhejiang University access guidance

Live verification: 2026-08-11. Recheck quarterly and before a stable release that depends on these routes.

Use only current authoritative Zhejiang University pages:

- [Library off-campus access navigation](https://libweb.zju.edu.cn/56334/list.htm): check the current WebVPN, CARSI, and RVPN routes here rather than relying on a hard-coded deep link.
- [Electronic resource usage rules](https://libweb.zju.edu.cn/2016/1014/c55987a2245977/page.htm): follow restrictions on credential sharing, excessive or systematic downloading, and redistribution.
- [Zhejiang University research integrity rules](https://pi.zju.edu.cn/2019/0920/c66998a2550400/page.htm): retain lawful attribution and research-integrity boundaries.

## Manual routing

1. Open the library navigation page and select the current route recommended for the target database.
2. Let the user complete unified identity authentication in the official page.
3. Search the verified DOI or exact title inside the library-provided database path.
4. Download only the items needed for the immediate research task and allowed by the resource license.
5. If access fails, record the database, citation, timestamp, and error class; then use the library help or document-delivery route shown on the current site.

CNKI, Web of Science, Scopus, SciFinder, Reaxys, and other subscriptions can change. Mention them as candidate resources only after confirming current availability in the library navigation. Recheck these links and the policy text quarterly before a stable release.
