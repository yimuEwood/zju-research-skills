# Lawful access routes

Apply the routes in order and stop once the requested version is obtained lawfully.

| Priority | Route | Evidence required | Typical fallback |
|---|---|---|---|
| 1 | Open publisher or repository copy | Full-text URL and license/access statement | Search by DOI/title in another repository |
| 2 | Official API or public supplement | Documented endpoint, terms, and successful item-level response | Publisher landing page |
| 3 | ZJU licensed access | Current library entry and interactive institutional authentication | Alternate library route or librarian help |
| 4 | Manual request | Complete verified citation and contact/request route | Interlibrary/document delivery or author contact |

Version labels matter: version of record, accepted manuscript, preprint, data supplement, correction, and retraction notice are not interchangeable. Record what was obtained.

For each attempt capture: `target_id`, `route`, `url`, `attempted_at`, `status`, `version`, `license_or_entitlement_basis`, `supplement_status`, and `notes`.
