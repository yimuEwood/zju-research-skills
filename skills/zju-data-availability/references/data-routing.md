# Data and code routing

- `public_repository`: public deposit with versioned persistent identifier and license.
- `discipline_repository`: domain repository required or strongly preferred for the data type.
- `controlled_access`: metadata public; access governed by a named process and authority.
- `within_article`: small source-data table or supplement is the complete supporting artifact.
- `reused_public`: cite the original dataset and exact version/accession.
- `third_party_restricted`: author cannot redistribute; name the controller and lawful request route.
- `justified_request`: only when legal, ethical, commercial, or material-transfer constraints prevent normal deposit; document the mechanism.
- `not_applicable`: explain why no new data/code artifact supports the work.

Repository selection factors include domain fit, persistence, identifier/version support, metadata, access controls, file limits, preservation, license choices, and journal/funder requirements. Verify live institutional routes before recommending them.
