# Chinese technical disclosure structure

Use the recipient’s current official template when supplied. A generic technical package contains:

1. 技术名称与所属领域.
2. 背景技术 and documented limitations.
3. 要解决的技术问题.
4. 技术方案 with components or ordered steps.
5. 有益效果 tied to evidence.
6. 附图说明 and claim-aligned diagrams.
7. 具体实施方式, alternatives, parameter boundaries, and examples supported by sources.
8. 关键创新点与拟保护点.
9. Source-to-feature table, prior-art ledger, and `[TO CONFIRM]` list for professional review.

Keep formal claims free of placeholders. If required support is missing, label the package incomplete and route questions to the inventor or patent professional.
