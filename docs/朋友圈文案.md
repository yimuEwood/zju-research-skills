# 朋友圈文案

## 短版

最近做完了一个面向浙大科研场景的开源项目：**ZJU Research OS**。

它不是一条“万能论文 Prompt”，而是 1 个 Research Director + 19 个专业 Skills：从文献检索、全文获取、精读与证据综合，到实验记录、统计审计、论文写作、制图、答审、数据开放和专利披露，用同一份可追溯 Research Mission 串起来。

这次迭代重点不是增加更多名字，而是把能力接通：检索会沿引文网络扩展并判断是否趋于饱和；阅读会抽取 Paper Spine，证据综合会保留冲突；实验设计直接交接给统计分析，写作、图表、数据开放和答审引用同一份结果注册表；证据和竞争假设还能继续编译成基金工作包或专利披露图谱。

简单说，它现在能把一个问题连续做成：跨库检索图 → 引文追踪与饱和判断 → 全文/补充材料/数据来源包 → Paper Spine → 冲突证据矩阵 → 可判别的竞争假设 → 实验与分析契约 → 同源论文、图件、答审和数据产物，并可继续生成基金工作包或专利披露图谱。

仓库仍保留 v0.4 的 legacy 内部三臂基线，但它不是正确率或第三方认证；v0.5.0-beta.1 没有拿旧数据冒充本轮升级后的新跑分，详细限制放在项目评测说明中。

中文优先，也针对浙大 CARSI / WebVPN / RVPN、电子资源规范和科研诚信路径做了本地化。20 个 Skills 目前都保持 Beta；v2 冻结留出集尚未配置或重跑，欢迎一起测试、找问题、提案例。

GitHub：https://github.com/yimuEwood/zju-research-skills

*社区开源项目，非浙江大学官方产品或服务。数字是 legacy/internal model-judged 快照；只有首批 7 项直接对照 Nature。评测边界见文末说明。*

## 中版

这段时间把 Nature Skills、K-Dense、Auto-claude-code-research-in-sleep、Claude Scholar、PaperSpine 等多个开源科研项目逐项拆解、核对许可证，再重新蒸馏成了一个中文优先的科研工作流：**ZJU Research OS v0.5.0-beta.1**。

我最想解决的并不是“再做一个会写论文的 Skill”，而是科研任务跨阶段以后经常出现的几个问题：检索何时算充分没有依据；论文精读把冲突和适用边界压成摘要；竞争假设没有落到能区分它们的实验；实验单位、重复和层级信息传不到统计阶段；同一个结果在正文、图注、答审和数据说明里被重复手填；基金与专利材料又从空白模板重新叙述一遍。

因此这个项目采用了 **1 个 Director + 19 个专业 Skills** 的结构。Director 先把研究目标转成带依赖、预算、风险、停止条件和人工闸门的 Research Mission，再让检索、精读、假设设计、实验记录、统计、写作、制图、评审等专业 Skill 各司其职。证据、主张、产物、决策和未决问题都用稳定 ID 传递，可以暂停、审计和继续，而不是靠一段越来越长的聊天记忆硬撑。

v0.5 的能力升级集中在三条主链：一是“多视角检索—引文网络扩展—饱和度判断—全文来源包—Paper Spine—冲突矩阵—判别假设”；二是“实验设计交接—领域分析契约—规范化结果注册表—写作/图件/数据/答审一致引用”；三是“证据与竞争假设—基金工作包/里程碑决策树，论文与实验记录—专利特征/证据/权利要求/现有技术查询图谱”。化学数据库比较也新增了终点、单位、基准、条件、方法和证据层级的共同对齐。

目前可公开复核的仓库内证据分为不同等级，不能混作一张排行榜：

- 首批 7 项的 **v0.4 legacy 内部模型评测**包含 70 个案例 × 3 个评测臂，共 210 份回答：ZJU 蒸馏版内部加权分 85.205/100，固定 Nature Skills 上游为 61.714，无 Skill 为 56.759。只有这一部分做了上游直接对照。
- 这组首批结果不是准确率或第三方认证：70 例中重用了 7 个 pilot，A/B/C 位置没有区组均衡，执行日志出现 3 次 Web 搜索和 17 次学术 MCP 调用，公开仓库也尚未包含完整回答、事件和逐条评分 raw records。
- 12 个扩展 Skills 的 84.385/100 和 84.58% gold-check 命中率，是 **整改后的开发集回归**；最终 120 条记录由 49 条基础运行和 71 条 remediation/amendment 记录组成，不是 untouched held-out，也没有其他项目对照。
- Director 的 20/20 是化学、材料、生医、农业、AI/计算五个领域的**确定性路由断言通过**；3/3 是新上下文压力测试，不代表科研答案正确率。
- 本地 103 个单元测试通过，其中包含 1 条发现→证据→假设→实验→分析→论文/图件/答审/数据的跨 Skill 集成链；项目包含 39 个离线处理/验证脚本。20 项 A/100 是结构一致性检查，其描述/组织/风格/结构的 25/30/20/25 权重参考 Claude Scholar scorecard，不是科研质量 100 分。

对浙大师生的额外适配包括：化学、材料、生医、农业检索与证据模板，中文/双语科研产物，浙江大学图书馆 WebVPN / CARSI / RVPN 的访问路由，以及 CNKI、Web of Science、Scopus、SciFinder、Reaxys 等候选资源提示。电子资源和科研诚信边界则集中引用校内官方入口。

项目 20 个 Skills 目前都保持 **Beta**。首批 7 项原有 Stable 晋级已暂停。v2 已实现内容指纹、首次运行锁、不可提前解盲的均衡分配、文件哈希清单、严格事件与评审身份检查；但新的独立留出集、真实三臂执行和公开脱敏记录仍未完成，所以 **没有 v2 新分数**。我更希望它成为一个有公开来源、有失败样本、有升级门槛的科研工具，而不是靠“最强”“全自动”几个字来宣传。欢迎老师同学拿真实但可脱敏的任务来测试，也欢迎提交 issue、金标准案例和改进建议。
